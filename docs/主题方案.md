# antd 主题方案

主题入口是 `src/theme/theme.ts` 的 `lightTheme` 和 `darkTheme`。浅色用 `theme.defaultAlgorithm`，深色用 `theme.darkAlgorithm`，再叠加下面已写入的 token。未出现在 `theme.ts` 里的 Map Token，保持算法结果。

色值来自 `docs/设计变量`，不用 `docs/全局样式/色彩.md`。两套同名变量编号方向不同。

## 已写入 ThemeConfig

### 尺寸与圆角

| Token                        | 值                                     | 原因                                                   |
| ---------------------------- | -------------------------------------- | ------------------------------------------------------ |
| `fontSize`                   | 14                                     | 正文用 14                                              |
| `controlHeight`              | 36                                     | 默认高度                                               |
| `controlHeightSM`            | 32                                     | 小号。只改 `controlHeight` 时算法得到 27               |
| `controlHeightLG`            | 44                                     | 大号。只改 `controlHeight` 时算法得到 45               |
| `borderRadius`               | 4                                      | 按钮、输入框、常规标签、选择器外框                     |
| `borderRadiusXS`             | 2                                      | 高度小于 28px 的徽标、小标签。基圆角为 4 时算法得到 1  |
| `Select.borderRadiusLG`      | 4                                      | 选择器弹层。弹层默认读全局 `borderRadiusLG`            |
| `Modal.borderRadiusLG`       | 8                                      | 只有 Modal 使用 8px                                    |
| `Modal.contentPadding`       | 24                                     | 弹层内容区四周内边距                                   |
| `Modal.titleFontSize`        | 16                                     | 与 `titleLineHeight` 一起得到 22px 行高                |
| `Modal.titleLineHeight`      | 1.375                                  | 标题行高 22px（16 × 1.375）                            |
| `Modal.headerMarginBottom`   | 24                                     | 标题区到内容区                                         |
| `Modal.bodyPadding`          | `16px 0`                               | 非表单内容区。表单弹层用 `styles.body.padding: 0` 覆盖 |
| `Modal.footerMarginTop`      | 24                                     | 内容区到底部按钮                                       |
| `Modal.confirmBtnsMarginTop` | 24                                     | 信息 / 成功 / 警告 / 错误等确认弹框，按钮区同上        |
| `fontFamily`                 | PingFang SC 开头，后接 antd 默认备用栈 | 正文用 PingFang SC。系统没有该字体时仍能显示           |
| `fontWeightStrong`           | 500                                    | 标题和选中项。antd 默认是 600。正文和按钮保持 400      |

`lineHeight` 不覆盖，使用 antd 默认值（约 `1.5714285714285714`）。页面根节点 `src/styles/global.css` 的 `body` 只写同一套 `font-family`，不改字重，正文保持 400。

Button 没有 `minWidth` 组件 token。带文字的实心、描边、虚线、填充按钮不在组件上写 `min-width`，由 `src/styles/global.css` 统一设为 `90px`。纯图标、圆形、`text`、`link` 不套这层最小宽。

### 颜色

功能色只覆盖稿面已有的档位：常规、悬浮、点击、三档浅色场景。对应关系：

| 设计变量                           | antd token                                                      |
| ---------------------------------- | --------------------------------------------------------------- |
| `primary/success/warning/danger-6` | `colorPrimary` / `colorSuccess` / `colorWarning` / `colorError` |
| `*-5`                              | `*Hover`                                                        |
| `*-7`                              | `*Active`                                                       |
| `*-1`                              | `*Bg`                                                           |
| `*-2`                              | `*BgHover`                                                      |
| `*-3`                              | `*Border`                                                       |

`danger-*` 写入 `colorError*`。链接色不再单独维护：`colorLink` / `colorLinkHover` / `colorLinkActive` 与主色 `primary-6` / `primary-5` / `primary-7` 相同。链接色没有单独的 Bg token。

文字：

| 设计变量       | antd token            |
| -------------- | --------------------- |
| `color-text-1` | `colorText`           |
| `color-text-2` | `colorTextSecondary`  |
| `color-text-3` | `colorTextTertiary`   |
| `color-text-4` | `colorTextQuaternary` |

深色 `color-text-2` 使用 `rgba(197, 197, 197, 0.77)`。

默认边框 `colorBorder` 使用设计变量 `color-border-3`：浅色 `#DFE1E5`，深色 `#4B4B4D`。

## 留给 antd 算法

以下 token 没有手写。算法在当前 seed 下的结果记在这里，方便和设计对稿。改了 `borderRadius` 或 `controlHeight` 之后，这些结果会变。

### 圆角

基圆角 `borderRadius = 4` 时，`genRadius` 的结果：

| Token               | 算法结果 | 本仓库                                    |
| ------------------- | -------- | ----------------------------------------- |
| `borderRadiusSM`    | 4        | 未覆盖                                    |
| `borderRadiusLG`    | 4        | 未覆盖。选择器弹层另用组件 token 固定为 4 |
| `borderRadiusXS`    | 1        | 已覆盖为 2                                |
| `borderRadiusOuter` | 4        | 未覆盖                                    |

Dropdown、Popover、DatePicker、Cascader、TreeSelect 的弹出层读取全局 `borderRadiusLG`，当前是 4。设计只规定了选择器弹层和 Modal。这些弹出层若要改成 8，需要单独的组件 token，不要改全局 `borderRadiusLG`，否则选择器弹层会跟着变。

### 控件高度

`controlHeight = 36` 时，`genControlHeight` 为小号 `27`、大号 `45`、极小 `18`。小号和大号已覆盖。`controlHeightXS` 仍是 **18**。

### 功能色缺档

稿面没有第 4、8、9、10 档。下列 token 由 `colorPrimary` 等种子色经算法生成，色值会随 antd 版本变化，不以稿面为准：

- `colorPrimaryBorderHover`、`colorPrimaryTextHover`、`colorPrimaryText`、`colorPrimaryTextActive`
- `colorSuccess*`、`colorWarning*`、`colorError*` 的同名四档
- `colorLink` 的 Bg / Border 派生 token 同样走算法；常规 / 悬浮 / 点击已与主色对齐

`colorInfo` 未指定。设计变量里的 `blue-*`（Brand2）不是 `colorPrimary`，也没有映射到 `colorInfo`。

### 中性色与背景

未覆盖，由当前算法生成（深色主题先走 `darkAlgorithm`）：

- `colorBorderSecondary`、`colorSplit`
- `colorFill`、`colorFillSecondary`、`colorFillTertiary`、`colorFillQuaternary`
- `colorBgLayout`、`colorBgContainer`、`colorBgElevated`、`colorBgSpotlight`、`colorBgMask`
- `colorTextLightSolid`、`colorBgBase`、`colorTextBase`

### 字体、阴影、间距、动效

未覆盖，使用 antd 默认种子及其派生结果：

- `fontFamilyCode`、各级 `lineHeight` 与标题字号。
- `boxShadow`、`boxShadowSecondary`、`boxShadowTertiary`
- `padding*`、`margin*`、`sizeUnit`、`sizeStep`
- `lineWidth`、`motion*`、`zIndexBase`、`zIndexPopupBase`

## 后续与设计对齐时再覆盖

这些项有稿面或建议映射，但本版故意不写进 `theme.ts`。

| 稿面                                             | 建议 token                                                             | 未写入的原因                      |
| ------------------------------------------------ | ---------------------------------------------------------------------- | --------------------------------- |
| 设计变量 `color-border-1` / `color-border-2`     | `colorSplit` / `colorBorderSecondary`                                  | 只定了默认边框用 `color-border-3` |
| 设计变量 `color-fill-1` 到 `color-fill-4`        | 页面底、容器底、悬浮、白底。编号和 antd `colorFill` 相反，不能同名对上 | 四层背景还没指定                  |
| Shadow-1 / 2 / 3                                 | `boxShadowTertiary` / `boxShadowSecondary` / `boxShadow`               | 阴影还没要求替换 antd 默认投影    |
| 标题 HarmonyOS Sans、数字 MiSans                 | 无对应全局 token                                                       | 需组件样式或项目 CSS 变量         |
| 全局样式扩展色（金、青、紫、品红、橙红、新生绿） | 项目 CSS 变量，不进 antd 语义色                                        | 尚未生成变量文件                  |
| 胶囊圆角 20px、圆形 50%                          | 使用处单独写                                                           | 不是全局 token                    |

除已写入的 `Select.borderRadiusLG` 和 Modal 圆角、内边距、标题行高相关 token 外，组件级 token（按钮内边距、表格头、菜单、表单标签等）本版不覆盖。
