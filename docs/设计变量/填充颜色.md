# 填充颜色

来源：设计交付 / 设计变量。

| 变量 | 适用场景 | 默认色值 | 深色色值 |
| --- | --- | --- | --- |
| color-fill-1 | 浅 | #F9FAFC | #343438 |
| color-fill-2 | 一般/常规/白底悬浮 | #F5F5F7 | #3B3B3F |
| color-fill-3 | 深/灰底悬浮 | #EAEBF0 | #2B2B2E |
| color-fill-4 | 纯白 | #FFFFFF | #17171A |

全局样式色板里的 `color-fill-*` 档位和场景与这张表不同，包含强调色、重色和更多背景档。两套不要混用。
