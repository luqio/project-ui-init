# 布局

整页下限、滚动条和卡片列表列数写在 `src/styles/global.css`。`/global` 的示例和代码都读这一份文件。

## 视口

整个页面最小宽度 `1040px`，最小高度 `700px`。

视口不小于这个尺寸时，页面本身不滚动。内容超出时只滚动内容区，左侧导航固定。低于这个尺寸时，滚动整个页面，内容区不再单独滚动，避免两条滚动条。

## 滚动条

横向和纵向同一套。滑块宽 `7px`，两侧各留 `2px`，圆角 `20px`。颜色取文字三级色，默认约 26% 不透明，悬停约 48%。轨道透明。

## 卡片列表

类名 `.card-grid`。断点看浏览器宽度。

| 浏览器宽度    | 列数                |
| ------------- | ------------------- |
| 小于 1280px   | 2                   |
| 1280px–1439px | 3                   |
| 1440px–1919px | 4                   |
| 1920px 及以上 | 5，单列不窄于 300px |

间距 `16px`。侧栏不计入断点：视口 1280px、侧栏 200px 时，内容区约 1080px，仍然是 3 列。
