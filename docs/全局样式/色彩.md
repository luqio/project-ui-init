# 色彩

来源：设计交付 / Color 与 Colors-Dark。这是全局色板，编号和场景与「设计变量」里的 `primary-*`、`color-fill-*`、`color-border-*` 不是同一套。

功能色档位：`1` 常规、`2` 悬浮、`3` 点击、`4` 禁用、`5` 特殊场景、`6` 浅色背景。深色板里部分 `4` / `5` / `6` 写成特殊场景 1 / 2 / 3。
