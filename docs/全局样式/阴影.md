# 阴影

来源：设计交付 / 其他 / Shadows。均为向下的投影，颜色 `#000000`，不透明度 `0.1`，扩展为 0。

| 变量 | 偏移 X | 偏移 Y | 模糊 | CSS |
| --- | --- | --- | --- | --- |
| Shadow-1 | 0 | 2 | 5 | `0 2px 5px rgba(0, 0, 0, 0.1)` |
| Shadow-2 | 0 | 4 | 10 | `0 4px 10px rgba(0, 0, 0, 0.1)` |
| Shadow-3 | 0 | 8 | 20 | `0 8px 20px rgba(0, 0, 0, 0.1)` |

稿面写法：`x,y,blur(0,2,5) #000000,0.1`，以及 Shadow-2、Shadow-3 的对应数值。
