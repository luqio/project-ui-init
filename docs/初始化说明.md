# 初始化说明

本仓库是 React 19、TypeScript、antd 6 的前端起点。工程工具链来自 `githubs/my-react-app`，依赖和请求层按本仓库重写。

## 技术栈

- React 19、TypeScript `strict`、Vite 6
- antd 6，主题在 `src/theme/theme.ts`
- React Router 7、axios
- ESLint（Airbnb React 规则 + typescript-eslint，禁止 `any`）、Prettier、husky、lint-staged
- `.npmrc` 打开 `legacy-peer-deps`：`eslint-config-airbnb@19` 声明的 peer 是 `eslint-plugin-react-hooks@4`，本仓库沿用 my-react-app 的 hooks 插件 5
- CSS Modules 类名导出为 camelCase，用于页面私有样式。公共组件用全局 `.css`，类名短横线。保留 Less 预处理，业务样式默认不用 Less 变量改 antd

相对 my-react-app 去掉的部分：React 18、Arco、`@tc/design-ui`、`@tc/components-react`，以及绑定旧接口 `status !== 1` 和登录跳转的 axios 拦截器。

## 目录

```
src/
  main.tsx                 # 入口
  App.tsx                  # ConfigProvider，切换 lightTheme / darkTheme
  theme/theme.ts           # 两套 ThemeConfig
  routes/index.tsx         # 路由
  components/<Name>/       # 公共组件，例如 PageLayout
  pages/<page>/            # 页面，例如 pages/basic
  services/request.ts      # axios 实例，baseURL 为 /api
  styles/global.css
  types/
docs/                      # 设计变量、全局样式、主题方案、本说明
icons/                     # 设计稿 SVG，尚未接入 src/assets
AGENTS.md                  # 模型约束索引
.agents/skills/            # 规范正文，各编辑器共用
```

路径别名 `@/` 指向 `src/`。开发服务器端口 `3002`。

## 请求

`src/services/request.ts` 只创建 axios 实例：`baseURL: '/api'`，超时 30 秒，上传 `FormData` 时去掉 `Content-Type`。业务错误码、401 跳转和提示组件留到接入具体后端时再加。

## 模型约束

改代码前读 `AGENTS.md`，再打开 `.agents/skills` 里对应的 skill。主题色值以 `docs/设计变量` 和 `docs/主题方案.md` 为准。
